# Coilover Suspension Lab

A responsive, single-page suspension model prepared for static web hosting. The publishable site is [`index.html`](index.html) in the repository root.

The model runs entirely in the visitor's browser. It has no server, build step, external libraries, or data collection.

## Publish with GitHub Pages

1. Put this project in a GitHub repository. The repository needs the `index.html` file for the site.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, then save.
4. Once GitHub Pages finishes publishing, share the URL shown in that settings page with the group.

GitHub Pages sites are publicly accessible by default, so anyone with the URL can open the model. The simulation itself does not send visitor data anywhere.
